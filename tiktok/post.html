Post to TikTok

Demo posting page for the Content Posting API audit. Connect your TikTok account, prepare a vertical video, then run the generated command on your own computer to publish it or save it as a draft.

Sandbox: until TikTok’s Content Posting audit is passed, videos published through the API stay private (SELF_ONLY) even if another privacy level is chosen. Drafts are never published by this tool — the creator finishes them in the TikTok app.

This tool does not schedule posts. TikTok posts immediately (Direct Post) or saves as a draft only.

1. Connect TikTok

Connect your TikTok account

Enter your Sandbox Client key (TikTok developer portal → your Sandbox app → Credentials, eye icon). The key is stored only in this browser. Your Client secret is never entered here.

Authorization URL opened in a new tab:

After you approve on TikTok, you are sent back to the callback page, which shows your authorization code. Copy that code — you will paste it into the uploader command in step 3. The code is single-use and expires quickly.
